# 해결안 추가비용 등급 및 검수 규정

문서ID: POL-COST-EVAL · v1.1 · 시행일 2026-01-01

> 가상 회사 데모용 목문서. 실제 계약이나 확정 사내 규정이 아닙니다.

## 1.1

본 규정의 금액 구간, 비용 예시, 절차 세부는 사용자 요청을 구현하기 위해 새로 정한 가상 사내 규정이며 회사의 확정 규정이 아니다. 버전은 v1.1이다.

## 2.1

추가비용은 기존 계획 대비 긴급 운송비, 납기 조정 수수료, 분할 수수료, 취소 위약금, 반품 처리비, 확정된 폐기 손실 등 비음수 비용의 합이다. 정상 발주 원금과 기존 재고 평가금액은 제외한다. 예상 절감액과 환급액은 별도 표시하고 추가비용에서 자동 차감하지 않는다.

## 2.2

통화는 KRW, 부가세 제외 정수 원이다. A등급은 0원 이상 50,000원 미만, B등급은 50,000원 이상 200,000원 미만, C등급은 200,000원 이상 500,000원 미만, D등급은 500,000원 이상이다. A에 가까울수록 추가비용 부담이 작다. 비용 미확정은 미평가이며 A로 간주하지 않는다.

## 3.1

계산기는 제안등급을 제공할 수 있으나 구매 담당자가 총액 견적, 수량, 날짜, 확약 유효기간과 근거를 검수하고 사내 기준에 맞는 평가등급을 직접 입력해 확정한다. 확정되지 않은 평가와 반려된 평가는 생산관리 비교 대상에서 제외한다.

## 3.2

후보 revision, 비용명세, 확약, 적용 규정 버전 중 하나라도 바뀌면 기존 평가는 무효다. 새 revision에 대해 구매 검수를 다시 한다. 생산 우선순위도 재결정하며 기존 승인 재사용은 금지한다.

## 4.1

생산관리 담당자는 확정 등급과 부족 해소 여부, 잔여 위험, 타 제품 영향, 수량·날짜를 보고 우선순위를 직접 정한다. 비용등급과 우선순위는 별도 값이며 A등급이 항상 1순위인 것은 아니다. 미해소 결품이 있는 후보는 실행 후보로 선정할 수 없다.

## 4.2

생산관리의 결정 후 구매 담당자가 발주 변경 승인 카드를 요청하며 팀장 승인 후에만 실행한다. 생산 일정 역제안은 생산관리 담당자가 최종 일정 변경을 수행한다.

## 5.1

생산관리에게는 검수 확정 등급, 검수자, 시각, 규정 버전, 부족 해소 여부와 수량·날짜만 전달한다. 추가비용 총액, 비용명세, 단가, 발주 원금, 평가금액, 견적 원문 및 금액 포함 자유서술은 전달하지 않는다. 구매는 비용 총액을 보되 계약단가를 보지 않는다. 팀장은 모두 조회한다.
