# 파워링크전자 공급계약

문서ID: CT-SUP02 · v1.1 · 시행일 2026-01-01

> 가상 회사 데모용 목문서. 실제 계약이나 확정 사내 규정이 아닙니다.

## 1.1

전원 모듈, 릴레이, 어댑터, 코인전지는 신규 발주 리드타임 28일이다. 수정진동자, 안테나, 캐패시터, 저항, LED는 14일이다. USB-C 커넥터와 전지 홀더는 28일이다.

## 2.1

설비 고장 시 지연 사실과 새 입고일을 구매 담당자에게 통보한다. 지연 사실 입력은 승인 대상이 아니며, 이를 해결하는 발주 조정은 승인 대상이다.

## 2.2

릴레이 1,200개 중 1,000개를 먼저 납품하는 협의를 할 수 있다. 총수량은 보존한다. 비용은 건별 총액 견적과 확약으로 검수한다.


## 3.1

계약기간 내 발행한 선발주는 계약 종료 후의 지정입고일에도 기존조건으로 납품할 수 있다. 품목별 MOQ·발주배수는 품목마스터를 우선한다. 포장단위 미만 잔량은 합의한 부분포장으로 납품 가능하다. 계약단가는 팀장권한에서만 조회한다. 이계약문서는가격원문을포함하지않는다.
