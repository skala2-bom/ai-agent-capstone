# 세미온반도체 공급계약

문서ID: CT-SUP01 · v1.1 · 시행일 2026-01-01

> 가상 회사 데모용 목문서. 실제 계약이나 확정 사내 규정이 아닙니다.

## 1.1

MCU, Wi-Fi 칩, BLE 칩 및 홀 센서를 공급하며 신규 발주 표준 리드타임은 56일이다.

## 2.1

기존 발주는 협력사 확약을 받아 납기를 당기거나 나누어 받을 수 있다. 분할 전후 총수량은 보존하며 각 납품은 100개 단위를 적용한다.

## 2.2

납기 연기는 협의 후 가능하다. 이미 입고된 발주는 변경할 수 없다. 긴급 운송비·분할 수수료는 건별 확약서의 총액으로 구매 담당자에게 전달한다.


## 3.1

계약기간 내 발행한 선발주는 계약 종료 후의 지정입고일에도 기존조건으로 납품할 수 있다. 품목별 MOQ·발주배수는 품목마스터를 우선한다. 포장단위 미만 잔량은 합의한 부분포장으로 납품 가능하다. 계약단가는 팀장권한에서만 조회한다. 이계약문서는가격원문을포함하지않는다.
