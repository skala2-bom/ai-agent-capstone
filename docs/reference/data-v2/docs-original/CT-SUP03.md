# 한결정밀 공급계약

문서ID: CT-SUP03 · v1.1 · 시행일 2026-01-01

> 가상 회사 데모용 목문서. 실제 계약이나 확정 사내 규정이 아닙니다.

## 1.1

케이스, 버튼, 자석, 나사의 신규 발주 리드타임은 21일이다. 박스, 설명서, 라벨은 7일이다.

## 2.1

미입고 케이스 발주는 협의 후 감량 또는 취소할 수 있다. 이미 입고된 물량은 발주 취소가 아니라 별도 반품으로 처리한다.

## 2.2

ECN-2026-014에 따른 옛 케이스 취소·반품은 담당자 협의와 팀장 승인을 거친다. 새 케이스 추가 발주는 기존 새 케이스 600개 발주를 중복 사용하지 않도록 한다.


## 3.1

계약기간 내 발행한 선발주는 계약 종료 후의 지정입고일에도 기존조건으로 납품할 수 있다. 품목별 MOQ·발주배수는 품목마스터를 우선한다. 포장단위 미만 잔량은 합의한 부분포장으로 납품 가능하다. 계약단가는 팀장권한에서만 조회한다. 이계약문서는가격원문을포함하지않는다.
