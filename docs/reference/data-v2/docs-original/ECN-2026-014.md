# 도어센서 케이스 설계변경 통지서

문서ID: ECN-2026-014 · v1.1 · 시행일 2026-12-01

> 가상 회사 데모용 목문서. 실제 계약이나 확정 사내 규정이 아닙니다.

## 1.1

대상은 FG300 도어 센서 케이스이다. P-CASE-300을 P-CASE-300B로 교체한다. MCU 교체가 아니다.

## 3.1

2026-11-30 생산 시작분까지 옛 케이스를 사용한다. 2026-12-01 생산 시작분부터 새 케이스를 사용한다. 적용일은 양끝 포함 규칙으로 BOM 유효기간과 일치해야 한다.

## 3.2

2026-12-01 이후 옛 케이스는 사용 금지한다. 미입고 발주는 취소를 협의하고 입고 재고는 반품을 협의한다. 협의 완료 전 자동 취소·반품하지 않는다.

## 4.1

SC3에서 생산일이 2027-01-04로 이동하면 옛 케이스 800개는 사용처를 잃는다. 새 케이스 800개는 21일 리드타임으로 2026-12-14까지 발주해야 한다.
