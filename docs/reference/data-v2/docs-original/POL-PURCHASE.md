# 구매 및 재고관리 규정

문서ID: POL-PURCHASE · v1.1 · 시행일 2026-01-01

> 가상 회사 데모용 목문서. 실제 계약이나 확정 사내 규정이 아닙니다.

## 1.1

본 문서는 가온스마트 시연을 위한 가상 규정이다. 생산 시작일에 부품 전량을 사용하고 입고 당일 사용 가능하다. 일수는 달력일이다.

## 2.1

음수 예상재고는 계획상 결품이며 실제 음수 재고를 저장하지 않는다. 안전재고 미만은 별도 경고한다.

## 2.2

고가 부품에 한해 당일 종료 재고에서 다음날부터 30일째까지의 확정 생산 소요와 안전재고를 뺀 양의 양수 부분을 원시 과잉으로 계산한다. 기존 상태보다 증가한 부분만 변경 영향으로 표시한다. 소모품은 과잉 판정에서 제외한다.

## 3.1

신규 발주는 품목별 리드타임을 적용한다. 품목별 MOQ와 발주배수를 seed.item에서 확인한다. 캐패시터·저항 MOQ는1,000개, LED는500개, 나사는300개, 그외구매품목은100개이며 발주배수는모두100개다. 운송포장수량과 MOQ는별도다. 안전재고 회복까지 포함해 올림한다. 기존 발주의 납기 당김은 신규 발주 리드타임으로 일괄 거부하지 않고 협력사의 확약 증빙과 팀장 승인을 확인한다.

## 3.2

추가 발주는 아직 입고된 사실이 아니다. 제때 발주 가능한 부족은 정상 발주 안내로 분류하고 미처리 상태의 원시 결품도 보존한다.

## 4.1

발주 변경, 감량, 취소, 분할 및 신규 발주는 구매 담당자 요청과 구매팀장 승인 후 백엔드가 실행한다. 생산 우선순위 결정은 발주 승인에 해당하지 않는다. 요청자와 승인자는 달라야 한다.

## 4.2

승인 도구·인자·대상 version과 실행 요청이 같아야 한다. 승인 후 이미 실행된 요청은 다시 실행하지 않는다. 거절 사유를 남기고 재제안은 별도 후보 revision과 새 승인으로 관리한다.


## 5.1

단일창고 WH01의 ESD·전자자재·기구포장·완제품 구역을 구분한다. 검수대기구역은 기준스냅샷에서0개다. 예정입고를현재재고에더하지않으며 검수합격수량만가용전환한다. 로트가용수량의합이 seed.inventory.on_hand와같아야한다. 고객주문과작업지시는생산계획을설명하는연결자료이며 소요를중복계산하지않는다.
