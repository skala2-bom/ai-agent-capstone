One-page recommendation

지금은 2개 ISO를 참조하고, 5개 판정 기준을 우선 구현

국제표준 · 참고 프레임
ISO 7573:2008

부품 명세서의 최소 정보 요건. 부품 식별, 수량, 명세서 누락 등 데이터 품질 검증의 참고 기준.

국제표준 · 참고 프레임
ISO 10007:2017

형상 식별, 변경 통제, 상태 기록, 감사. ECN/Revision/승인 이력 관리에 적용.

중요: 이 표준들은 결품 수량, 안전재고, 30일 과잉재고 기준을 직접 규정하지 않습니다. 수치 임계값은 기획안과 가상 회사 정책으로 설정하며, 인증·ISO 적합 판정을 주장하지 않습니다.

02

그렇다면 판단 기준을 어떻게 정할까?

표준 문구에서 임계값을 찾기보다, 업무 위험 → 측정식 → 경계 조건 → 테스트 데이터 순서로 확정합니다.

STEP 01 · 근거 구분

출처 등급 표시

ISO 참고, 기획안 확정, 우리 팀 신규 제안, 추후 검증 필요를 분리합니다. 문서에 없는 규칙은 ISO 의무사항처럼 쓰지 않습니다.

STEP 02 · 실패 비용

무엇이 더 위험한가

생산 중단과 무효 Revision 사용은 높은 우선순위, 안전재고와 과잉은 주의 수준. 구매 실행은 언제나 승인 필요.

STEP 03 · 수식 정의

경계값을 고정

‘0 미만’과 ‘0 이하’를 구분하고, 당일 입고 사용 가능 여부, 30일 범위, 안전재고 포함 여부를 정확히 명시합니다.

STEP 04 · 골든셋 검사

오탐과 미탐 확인

기획안 SC1~SC4를 회귀 테스트하고, 경계값·날짜·수량을 바꾼 10~20개 사례로 정책을 검증합니다.

F-01 · 시점별 예상 재고
결품·안전재고 판정에 사용하는 값
P(t) = 초기재고 + t까지 누적 입고 − t까지 누적 생산소요

구매 부품의 소요량은 유효한 다단계 BOM을 전개해 계산합니다. P(t) < 0은 실물 재고가 음수라는 뜻이 아니라 계획상 충족하지 못한 소요를 나타냅니다.

F-02 · 생산 소요량
제품별·부품별 기초 계산
소요량(p,m,t) = 생산수량(p,t) × BOM 전개수량(p,m,t)

허브에 들어가는 Wi-Fi 모듈과 그 내부 Wi-Fi 칩을 이중으로 합산하지 않도록, 이번 시연에서는 재고를 관리하는 구매 부품 단위로 전개합니다.

F-03 · 고가 부품 과잉량
30일 관찰 정책 · 내부 기준
과잉량(t) = max(0, P(t) − 안전재고 − 향후 30일 소요량)

기획안 SC3의 계산과 일치하는 권장 명시식입니다. 기간은 t 다음 날부터 30일. 과잉 경고 ≠ 즉시 폐기 결정입니다.

F-04 · 발주 가능 여부
데모의 역산 규칙 · 내부 기준
가장 늦은 발주일 = 필요일 − 기준 리드타임

시연에서는 달력일로 계산하고, 필요일 당일 입고는 사용 가능하다고 가정합니다. 공급사 확약·휴일·검수시간 반영은 MVP 밖입니다.

기준을 정하는 근거: 날짜·수량·안전재고·고가 여부는 기획안의 초기 데이터에서 가져옵니다. ISO 7573과 ISO 10007은 각각 어떤 정보를 관리할지, 어떤 변경통제 절차를 기록할지의 참조 역할입니다.

04

기획안 4개 시나리오에 대입하면

아래 값은 사용자 제공 기획안의 날짜와 예상재고 수치를 사용합니다. 시나리오별 버튼을 눌러 확인해 보세요.

SC2의 일부 스위치 케이스 및 릴레이 수요는 기준일에 신규 발주하면 제때 조달 가능한 정상 안내로 구분해야 합니다. 위험 예측과 ‘발주로 해결 가능한 소요’를 하나의 결품 오탐으로 섞지 않는 것이 중요합니다.

07
팀에서 확정해야 할 정책 6개
기획안에 없거나 모호한 부분입니다. 아래 권장값은 구현을 위한 제안이며, 최종 요구사항은 팀 합의가 필요합니다.

    

      
Q1. 안전재고를 물리적으로 사용 가능한가?
권장: 사용 가능하지만 P(t) < 안전재고이면 경고. 안전재고 부족을 결품과 혼동하지 않습니다.

      
Q2. 30일 이후 생산 예정 재고는 폐기 대상인가?
권장: 아니요. ‘과잉 주의’로만 표시하고, 31~90일 수요 및 취소 가능 여부를 보여줍니다. 8주 리드타임 부품의 오탐을 방지합니다.

      
Q3. 같은 부품의 여러 날짜 부족량을 더할까?
권장: 날짜별 부족 이벤트는 모두 제시하되, 추가 구매 수량은 입고·배분·생산 조정 후 재시뮬레이션으로 산출합니다.

      
Q4. ECN이 미승인 또는 적용일 불명확이면?
권장: 자동 사용 가능 판정 금지. ‘규정 확인 필요’로 보류하고, 승인된 변경 문서와 생산일의 효력 관계를 확인합니다.

      
Q5. 이론적 납기 가능과 실제 확정 납기는?
권장: 두 상태를 분리합니다. LT-001이 가능이라고 하더라도 공급사가 확약하지 않았다면 ‘구매 요청 후보’로만 표시합니다.

      
Q6. 검증 기준을 언제 다시 조정할까?
권장: MVP에서는 기존 30일·안전재고를 고정하고, 테스트 10~20개 수행 후 과잉 오탐과 납기 미탐을 보고 버전업합니다.
